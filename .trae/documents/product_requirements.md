## 1. 产品概述

现代个人博客系统，专为GitHub用户guoshaoran设计。展示个人技术文章、项目作品和开源贡献，提供优雅的阅读体验和高效的写作环境。

* 解决技术博客展示、文章管理和GitHub项目集成的需求

* 面向开发者和技术爱好者，提升个人技术影响力

* 通过现代化设计和交互体验，打造专业的个人技术品牌

## 2. 核心功能

### 2.1 用户角色

| 角色  | 认证方式           | 权限描述                |
| --- | -------------- | ------------------- |
| 访客  | 无需登录 / GitHub登录 | 浏览内容、发表评论、搜索项目      |
| 管理员 | GitHub OAuth (guoshaoran) | 全量权限：发布/编辑文章、删除评论 |

### 2.2 功能模块

1. **炫酷开屏**：基于 Canvas 实现的交互式粒子或矩阵流动画
2. **首页轮播**：最新文章展示，支持点击跳转
3. **项目中心**：自动同步 `https://github.com/guoshaoran/` 的开源项目
4. **内容管理**：内置 Markdown 富文本编辑器，支持实时预览
5. **互动评论**：支持嵌套回复、表情包、Markdown 评论内容
6. **多色主题**：黑色系 (Dark) 与 肉色系 (Nude/Beige) 风格切换

### 2.3 页面详情

| 页面名称  | 核心功能  | 交互细节                            |
| ----- | ----- | ------------------------------- |
| 首页    | 轮播图 & 简介 | 视差滚动、响应式轮播图           |
| 项目页  | GitHub 同步 | 自动拉取仓库信息，点击跳转至 GitHub 页面 |
| 文章详情 | 评论系统 & 编辑 | 管理员可直接在页面触发编辑模式           |
| 全局    | 主题切换 & 开屏 | 沉浸式 Canvas 动画，本地持久化主题选择    |

## 3. 设计规范

### 3.1 主题风格
* **黑色系 (Dark)**：深邃的背景 (#09090b)，配合蓝色高亮 (#3b82f6)
* **肉色系 (Nude/Beige)**：温暖的肤色调背景 (#fdf5e6/f5f5dc)，配合咖啡色或深木色文字 (#4a3728)

### 3.2 响应式断点
* 桌面端 (>1024px)：完整网格布局
* 移动端 (<768px)：堆叠布局，隐藏次主要装饰元素

## 4. 性能与安全
* **Lighthouse 评分**：目标 90+
* **数据安全**：使用 Supabase RLS 策略保护文章与评论数据
* **身份验证**：GitHub OAuth 2.0 授权流
